## What it does

- **Prayer times computed on the device** with [adhan-js](https://github.com/batoulapps/adhan-js), cross-checked against several recognised calculation methods. Nothing is fetched at runtime.
- **Northern-latitude rule** used by mosques in Germany: Isha 90 minutes after Maghrib, Fajr 90 minutes before sunrise, all year. Where the shown time differs from the astronomical one, the app says so.
- **Works anywhere in Germany, and offline.** GPS or a manual city pick from 1,130 bundled German cities. About 2,000 mosques bundled with distance, from OpenStreetMap and Overture Maps.
- **Local adhan notifications**, scheduled on the phone. Optional silence during prayer.
- **Qibla compass** from true north, monthly timetable, Hijri calendar with upcoming occasions, Ramadan mode, home-screen widget.
- **Adhkar and gentle reminders**, morning, evening and bedtime, plus a tasbih counter.
- **Mosque screen**: turn any phone, tablet or TV into a prayer-times board with the mosque's name and Jumuʿa time, a rotating photo with a duʿāʾ, and a TV-remote friendly layout.
- **No data collected.** No analytics, no advertising IDs, no server, no login.

## Deutsch

**Gebetszeiten für Deutschland – offline, ohne Werbung, ohne Tracking.**

Die App berechnet die fünf täglichen Gebetszeiten direkt auf dem Telefon, aus deinen Standortkoordinaten. Kein Server, keine Verbindung, kein Warten. Sie folgt der festen Regel, die Moscheen in Deutschland für nördliche Breiten anwenden: Ischa immer 90 Minuten nach Maghrib, Fadschr immer 90 Minuten vor Sonnenaufgang.

Qibla-Kompass vom geografischen Norden, Monatsübersicht, Hidschri-Kalender, Adhkar für morgens, abends und vor dem Schlafen, Tasbih, Moscheen in ganz Deutschland mit Entfernung und ein Moschee-Bildschirm mit dem Namen deiner Moschee und der Dschumuʿa-Zeit. Dein Standort verlässt das Gerät nicht, es werden keine Daten erhoben.

## Türkçe

**Almanya için namaz vakitleri – çevrimdışı, reklamsız, takipsiz.**

Uygulama beş vakti doğrudan cihazınızda, konum koordinatlarınızdan hesaplar. Sunucu yok, bağlantı yok, bekleme yok. Almanya'daki camilerin kuzey enlemleri için uyguladığı sabit kuralı esas alır: yatsı her zaman akşamdan 90 dakika sonra, imsak her zaman güneşin doğuşundan 90 dakika önce.

## English

**Prayer times for Germany – offline, no ads, no tracking, no accounts.**

The app works out the five daily prayer times on the device itself, from your location coordinates. No server, no connection, no waiting. It follows the fixed rule mosques in Germany apply for northern latitudes: Isha 90 minutes after Maghrib, Fajr 90 minutes before sunrise, all year round.

Qibla compass from true north, monthly timetable, Hijri calendar, morning, evening and bedtime adhkar, a tasbih counter, mosques across Germany with distance, and a mosque screen that shows your mosque's name and Jumuʿa time on any display. Your location never leaves the device and nothing is collected.

## Repository layout

```
mobile/          Android app (Expo SDK 57 / React Native, expo-router)
src/             Web PWA (Next.js) – the original clock, still serving mosque wall displays
shared/          Prayer engine, calculation methods, consensus, qibla, city and mosque data
scripts/         Data fetchers (cities, OSM and Overture mosques), engine validation
tests/           Vitest suites for the shared engine and mobile logic
docs/            Play listing copy (4 languages), privacy policy, store screenshots
```

## Getting started

**Android app**

```bash
cd mobile
npm install
npx expo run:android      # needs Android Studio / an emulator or a device with USB debugging
```

**Web PWA**

```bash
npm install
npm run dev               # http://localhost:3000
```

**Validate the engine**

```bash
npx tsx scripts/validate.mts
```

Computes today's prayers via the local engine and diffs each one against a published reference. Exits non-zero if any prayer drifts more than 120 seconds.

**Tests**

```bash
npm test
```

## Contributing

Issues and pull requests are welcome. Useful places to start:

- **Mosque data.** Wrong name, missing mosque, closed one? Edit `shared/mosques-curated.ts`; it overrides the OpenStreetMap and Overture layers.
- **Translations.** UI strings live in `mobile/src/lib/i18n`. Arabic is the base language.
- **Calculation rules.** Methods and the northern-latitude rule are in `shared/methods.ts` and `shared/prayer-engine.ts`, with tests in `tests/`.
- **Store listing.** The full Play Console copy for all four languages is in `docs/play-listing.md`; the screenshots are in `docs/shots/store/`.

Please keep the app's promises intact in any change: no network calls at runtime, no analytics, no ads.
